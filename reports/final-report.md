## 学习体系与正文

原八章主线已合理，因此保留“测量语言→器件→平台→可信数据→视觉／点云／听觉→融合”。章内把应用案例放到必要基础之后，把重复概念集中在第一次出现处完整解释。学习指南解释三条贯穿线：模型、不确定性、实现；符号页统一坐标、向量、频率、单位、误差和概率约定。

174个知识点全部有稳定编号、显式锚点与来源页段，其中160项课件详讲、14项课件仅提及；核心／支撑／延伸表示学习地位，不代表考试重点。正文补充动机、符号、关键推导、数值复核、反例与边界；新增内容均不冒称教师讲授。知识清单及逐页索引由同一份Markdown标记和人工主题表生成。

八组练习分开列出原题、来源、课件给出的答案和编写者参考解。缺数据题给出可执行的解题流程与必要条件，不伪造原始数据或唯一数值答案。旧CCS、MATLAB与硬件截图没有被描述成可直接运行的完整工程。

已直接修订正文中的高风险问题，例如：有符号偏差与MAE、端点码距与量化箱宽、幅度分贝、采样与带宽、归一化滤波、相机齐次尺度、多视图标定、PCA协方差、RANSAC概率、TDOA符号、Kalman方差、D-S漏质量和BP符号。每项保留原页与修订理由，详见`docs/corrections.md`及四份来源审阅报告。

## 教学可视化与计算

18幅自制SVG各承担一个主要问题：知识依赖、测量链、运动拖影、超声往返声程、正交编码器相位、启动资源依赖、I²C稳定窗口、低通阶跃、弦长弓高、Runge对照、针孔投影、视差深度、PCA法线、ICP交替、相关峰符号、TDOA声程差、融合高斯密度、Bel／Pl间隔。

图形有可访问标题与说明，采用线型和文字辅助区分；科学曲线使用实际计算，不使用生成式位图。低通、视差与插值图共享计算模型。明暗主题文字采用当前文本色；窄屏允许图和公式局部滚动，避免压缩标注。反向审查已移回弦长图的正确位置，统一D-S图与正文示例，删除TDOA图中未声明角度方向的多余近似式。

仅保留一项低通权重交互，提供标签、键盘调整、重置和服务器渲染静态曲线。没有随机抽样实验，不以单次模拟证明结论。Node.js确定性复现包包含源模型、测试、数值JSON和CSV；已在临时目录解压并实际运行验证。

## 浏览器验收

使用真实浏览器查看生产构建，桌面有效视口约1,200 CSS px、窄屏325 CSS px，并检查390 CSS px附近布局。未用源码检查替代实际观察。

- 浅色／深色：正文、公式和SVG标注可读，修复了深色SVG文字变黑的问题。
- 窄屏：修复VitePress默认320px最小宽度造成的整页溢出；公式和图只在局部滚动，根页面宽度检查一致。
- 搜索：查询PHAT能定位第七章GCC-PHAT知识点、原题和来源记录。
- 交互：键盘右箭头使α由0.25变0.30，k=10输出由0.8665变0.9176；重置返回默认值。
- 无脚本：使用CSP阻止页面脚本，正文、预渲染公式、静态图、前后节链接和默认低通曲线仍可读；搜索、主题开关和参数调整需脚本。移动端可由正文链接和前后节继续阅读。
- 控制台：正常预览页面未见运行错误。禁用脚本检查中的CSP阻止日志属于预期。
