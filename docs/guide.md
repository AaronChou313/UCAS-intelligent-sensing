# 学习指南与知识地图

本课程不是传感器型号目录，也不只是信号处理算法集合。它把“物理量能不能被观察”“观测怎样被采到”“数字是否可信”“如何解释空间与时间关系”“怎样整合不同来源”连接成一个完整工程问题。学习时始终带着一个对象：你究竟想知道世界中的哪个量，手中实际得到的又是什么？

## 推荐学习路径

八章课件的主体顺序合理，因此保留原章结构。章内把平台文件开头的案例移到基础之后，把重复概念首次完整解释、后续链接回顾。视觉、点云与听觉之间可以按目标调整顺序；融合放在读者已经理解观测模型与误差之后。

## 三条贯穿全书的线

**模型线**：物理转换 $y=f(x;\theta)$ → 标定求参数 → 观测反演 → 多源估计。它提醒你分清“读数”“被测量”和“模型参数”。

**不确定性线**：噪声与偏差 → 滤波/校正 → 几何估计误差 → 概率或证据融合。平均并不总能消除误差，增加信息也不自动提高准确度。

**实现线**：采样与ADC → 接口/缓冲 → 计算与调度 → 输出与失效处理。任何算法都要交代单位、时间、坐标和有效域，理论正确只是系统可用的一部分。

## 建议的学习方式

先读章节开头的问题，再沿正文推导一次；把每个公式的已知量与待求量写在纸上。对数值例题，先估算量级，再运行[计算实验](./practice.md)交叉检查。阅读图形时先看图前提出的观察任务，图后再核对数学结论，避免把一次模拟或二维示意当作一般证明。

复习时从[知识清单](./checklist.md)选一个知识点，合上正文解释它的前提和反例；若只能记公式，回到其引入问题。教师原题与编写者自测分别标注；课程实际作业提交、考试安排以教师正式通知为准。
