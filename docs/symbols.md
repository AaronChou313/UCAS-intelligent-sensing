## 数学记号

| 记号 | 对象与含义 | 阅读时要检查 |
| --- | --- | --- |
| $x,y,z$ | 标量、坐标或信号，按当前节定义 | 单位及是否与之前同名量相同 |
| $\mathbf x\in\mathbb R^n$ | $n$维实列向量 | 元素顺序与坐标系 |
| $A\in\mathbb R^{m\times n}$ | $m$行$n$列矩阵 | $A\mathbf x$的结果为$m$维 |
| $\hat x$ | 对$x$的估计 | 帽号不表示已知真值 |
| $x^\ast$ | 参考/理想值，按局部说明 | 参考本身是否有不确定度 |
| $\bar x$ | 样本均值或点集质心 | 是否含$1/N$归一化 |
| $t,k,i,j$ | 连续时间、离散步、样本/坐标索引 | 下标并非都表示时间 |
| $f_s,T_s$ | 采样率Hz与采样周期s，$T_s=1/f_s$ | 不能与带宽或曝光时间互换 |
| $\sigma,\sigma^2$ | 标准差与方差 | 方差单位是原单位的平方 |
| $P,Q,R$ | 状态协方差、过程噪声与观测噪声协方差（融合章） | 别与相机旋转矩阵$R$或物理电阻$R$混用 |
| $K$ | 相机内参矩阵或Kalman增益，局部重定义 | 两者含义完全不同 |
| $R,\mathbf t$ | 几何章的旋转矩阵与平移向量 | 映射方向必须写清 |
| $p(\cdot),P(\cdot)$ | 密度/概率，依当前定义 | 连续密度不是点事件概率 |
| $\mu_A(x)$ | 模糊集合$A$中的隶属度 | 不是$x$属于$A$的随机概率 |
| $m(A),Bel(A),Pl(A)$ | 基本概率分配、信任与似然界 | 质量分配需合法归一化 |

全书不强迫同一字母跨所有领域只用一种含义；遇到跨章复用会就地重述。读者应优先采用当前公式前的定义。

## 坐标、角度和单位

几何默认列向量；外参写出“从哪个坐标系映射到哪个坐标系”。像素坐标$(u,v)$与相机坐标$(X_c,Y_c,Z_c)$不使用相同单位。齐次关系的整体尺度不能作为每个点相同的真实深度。

三角函数、数值程序与推导默认使用弧度；给定角度须显式转换，$\theta_{\rm rad}=\theta_{\rm deg}\pi/180$。频率$f$用Hz，角频率$\omega=2\pi f$用rad/s。

bit与byte相差8倍；MB按$10^6$ byte，MiB按$2^{20}$ byte。毫米、米、微秒和毫秒在代入公式前统一。图中比例未按物理真实比例绘制时注明“示意”。

## 推导中的常见门槛

矩阵求逆需要方阵且可逆，最小二乘法中的法方程还要求相应秩条件；存在噪声时，直接取逆可能数值不稳。平均降低方差通常需要独立或明确相关结构，不能消除共同偏差。正态分布的3σ规则带有分布假设，单个超限值不是错误测量的充分证明。
