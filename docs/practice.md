## 确定性计算实验

本项目使用Node.js 22+，不依赖额外数值库。克隆仓库后运行：

```sh
npm ci
node scripts/compute.mjs
node --test tests/models.test.mjs
```

输入数据分成两类：S01第85张的激光/双目表与S05原题等来自课件；低通阶跃、二维点集和合法D-S示例是明确标注的编写者合成数据。没有随机抽样，因此不涉及随机种子或抽样误差。生成结果为[data/results.json](/data/results.json)及[低通响应CSV](/data/lowpass-step.csv)，可从[完整复现包](/code/reproduce.zip)下载源代码、测试和运行说明。

建议先手算，再核对程序：

1. 对S01表计算有符号误差、MAE与RMSE，观察为何平均偏差可相互抵消。
2. 固定单位阶跃输入，比较低通权重0.25和0.75，核对递推与几何级数闭式结果。
3. 用两个独立高斯信息源分别通过Kalman更新与精度加权公式求同一后验，检查方差单位。
4. 改变双目视差，验证深度与视差反比；零视差拒绝给出有限深度。
5. 对直线$y=2x+3$点集估计PCA法线，核对它与切向量垂直；退化点集应报告无法辨识。
6. 用RANSAC成功概率反验迭代次数，而非只比较某一个整数。
7. 检查D-S质量和为1；完全冲突与漏质量输入应明确拒绝，不能悄悄归一化成别的问题。

## 一项轻量交互

这个组件只回答一个问题：一阶低通的权重怎样影响跟踪速度？递推为 $y_k=\alpha x_k+(1-\alpha)y_{k-1}$，本例初值为0，输入在$k=4$从0变1。纵轴无量纲，横轴为样本编号；它不模拟真实传感器噪声。

较小权重让输出更慢趋近新值。实际采样周期改变时，即使权重不变，物理时间上的响应速度也会改变；应结合第四章理解时间常数。无JavaScript时保留默认静态曲线与解释。
