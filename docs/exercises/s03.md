# 平台章案例与实践边界

## 教师拓展练习：瓶内杂质检测

来源：S03 第1张，方案与流程示例见第2—11张。原页列出需设计的相机参数（Sensor、接口）、镜头参数、光源参数与检测流程；要求检测尺寸不小于0.1 mm的漂浮、悬浮、沉底杂质，包括纤维、玻璃渣、色块、毛发、油渍。

编写者参考思路：先明确视场与目标像素数，再设计曝光与光源，使不同位置/材料的杂质形成足够对比；由旋转、停止、拍摄与分拣时序确定处理预算；最后验证漏检、误检与最坏延迟。课件第2张的2000像素推算基于100 mm宽度与2像素准则；无法从该页确认“38”的具体光学含义，不将1.5 mm焦距当作完整选型答案。

资料未提供原始图片序列、人工标签、曝光设置和完整程序，因此不能复现检测精度。静态结果截图可用于理解流程，不能当作算法性能评估数据。

## 教师课堂示例：机器人仿生视觉

来源：S03 第139—142张。要求为相机体积不大于50×50×40（该页未明示单位）、重量不大于100 g、最大100帧/s@512×512、最大分辨率1024×1024、实时三维点云512×512@20帧/s。方案举例为AR0134、FPD-Link III、DSP+FPGA和网口。

## 编写者自测与参考解

1. 上述8 bit单通道100帧/s图像流，仅像素载荷需要约209.72 Mbit/s。若接口只有100 Mbit/s，即使没有协议开销也无法原样实时传输。可选择降低输出分辨率/帧率、压缩、只输出特征，或换更高吞吐接口；每个方案需重新评估信息损失与延迟。
2. 假设采集10 ms、处理25 ms，串行一帧35 ms；理想两级流水稳定后的周期为25 ms，但第一帧延迟仍至少35 ms。必须另外考虑缓存、资源争用与传输。
3. 为什么软件模拟器通过仍不代表上板可靠？它未必包含真实外设时序、电气噪声、DMA争用、驱动和传感器失效。

这些是编写者增加的练习，不是新增教师作业。没有板卡连接时，只能验证算术与模型，不能声称完成硬件实验。
