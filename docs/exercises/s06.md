# 第六章作业：点云几何与鲁棒拟合

以下4题均来自 S06 物理幻灯片94。题目文字与图中已核对条件单独列出；解答均为**编写者参考解，非教师官方答案**。提交范围、格式及截止日期以教师通知为准。

## 1. PCA法线

**原题。** 二维平面曲线上的5点为$(-2,-1),(-1,1),(0,3),(1,5),(2,7)$，利用PCA求点$(0,3)$处的单位法线。

**参考解。** 均值为$(0,3)$，中心化坐标为$(-2,-4),(-1,-2),(0,0),(1,2),(2,4)$。采用$1/5$协方差约定：

$$
C=\begin{pmatrix}2&4\\4&8\end{pmatrix}.
$$

特征多项式为$\lambda(\lambda-10)$。最小特征值0对应$2n_x+4n_y=0$，故可取$\mathbf n=(-2,1)^\mathsf T/\sqrt5$，反向同样有效。直接用直线$y=2x+3$的切向$(1,2)$交叉检查：内积为0、法线长度为1。由于五点严格共线，这里是整体同一条直线的法线；不是从五个点推断任意未知曲线的唯一微分性质。

## 2. 模板原点与形态学

**原题。** 对课件图像做腐蚀和膨胀。与课件演示不同，$2\times2$全1模板的原点在右下角。

**图的可检索转写。** 行从上至下、列从左至右，1为目标、0为背景，原图为5行10列：

```text
0000000000
0011111000
0001111100
0000111110
0000000000
```

**参考解与约定。** 图外固定为背景，坐标用$(行,列)$，模板偏移为$B=\{(-1,-1),(-1,0),(0,-1),(0,0)\}$。腐蚀以$A\ominus B=\{x:x+B\subseteq A\}$计算，结果为：

```text
0000000000
0000000000
0000111000
0000011100
0000000000
```

按集合加法的膨胀$A\oplus B=\{a+b:a\in A,b\in B\}$，结果为：

```text
0111111000
0111111100
0011111110
0001111110
0000000000
```

这份课件的文字又使用“模板覆盖任一目标即输出”的扫描叙述。若直接用同一$B$而**不反射模板**进行该扫描，计算的是$A\oplus(-B)$，结果不同：

```text
0000000000
0011111100
0011111110
0001111111
0000111111
```

模板原点非中心时，反射约定会显性影响位置。上面保留两种结果及定义，不将二者混成一个答案。实际提交需与课堂采用的扫描/反射及边界规则一致；这属于原课件定义与示意的约定差异，而非仅一个数值算错。

## 3. ICP思路和原理

**原题。** 简述ICP配准思路和原理。

**参考解。** 从粗初值出发，为变换后的源点寻找目标近邻；固定对应，最小化点对平方距离，先利用重心关系消去平移，再通过SVD求满足行列式$+1$的旋转；更新源点并重复寻找对应，至误差变化、位姿变化或迭代次数满足停止条件。它交替优化对应关系与刚体参数。当前对应的最优刚体解不等于全局配准最优，重叠不足、对称结构和错误初值都可能导致失败。

## 4. RANSAC最少采样次数

**原题。** 数据错误率0.5，模型需要拟合3个参数，希望至少取得一次良性取样子集的概率为0.9，求最少采样次数并写步骤。

**参考解。** 按题目与课件的最小样本假定，每次抽3个点，独立抽样近似下全内点概率为$(1-0.5)^3=0.125$。$M$次至少成功一次的概率为$1-0.875^M$，故

$$
M\ge\frac{\ln0.1}{\ln0.875}=17.2437735\ldots.
$$

取上界为18次。检查17次尚未达到0.9、18次达到，可防止误用四舍五入或向下取整。一般问题中“参数数目”不一定等于最小样本数，本题按三点非退化样本理解；平面拟合还要求三点非共线。
