- S01封面2025-09-15，安排页含2026-12-14考试日期，真实物理页86而页脚多写/81。

- S04封面2026-10-04；S05、S06、S07封面2026-10-14。S05文件第五章、封面第8讲；S06第11讲；S07第7讲。文件章号、讲次及页脚不作同一个编号体系。
