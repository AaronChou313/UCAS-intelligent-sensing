# 智能传感与信息处理

<div class="course-intro">

传感器给出的数字，怎样才能成为可以信任和使用的信息？

从电阻、电势、光和声的物理转换开始，经过嵌入式采集、误差处理与几何建模，最后把多路观测汇成对世界的判断。本教材围绕这条主线，重写当前八章课件，补足独立阅读所需的符号、推导与方法边界。

## 怎样使用这本教材

第一次学习按[推荐路线](./guide.md)阅读；遇到符号先查[统一约定](./symbols.md)。复习时用知识清单直接定位定义、推导或边界。每章的来源编号都能回到[逐页覆盖记录](./coverage.md)和原页PDF。

练习页把教师原题与编写者参考解分开。程序实验使用明确给定或标为合成的数据，不把模拟当证明。教材对课件疑义的处理见[公式修订记录](./corrections.md)。
